# תמונות

- `models/<model-id>/<color>/` – תמונת סטודיו אחת לכל צבע.
  - קובץ ה־PNG הוא המקור שהועלה, ונשמר ללא שינוי.
  - לצידו קובץ `.webp` באותו שם (איכות 90, שקיפות ללא אובדן) – זה הקובץ שהאתר מציג.
  - וקובץ `.thumb.webp` (320×256) – תמונה ממוזערת לרשימת הדגמים.
- `gallery/` – תמונות אווירה (`<model-id>-01.webp`, …).
- `brand/` – לוגו Royal Enfield ולוגו D.L.B MotoSport, בקבצי המקור, ללא שינוי.

הרשימה המלאה של התמונות הנדרשות: `docs/images-checklist.md`.
אחרי העלאת תמונה יש לחבר אותה לצבע ב-`assets/data/models.js` (שדה `image`).
