# רשימת תמונות להעלאה

כל התמונות עולות לענף `claude/great-clarke-tv3zid` ב-GitHub. בכל תיקייה: **Add file → Upload files**.
אחרי ההעלאה, שלחו לי את שמות הצבעים המדויקים. אני אחבר אותם ב-`assets/data/models.js`: שם הצבע, עיגול הצבע והקובץ.

**אין צבעים מאומתים ברשימה הזו.** לא הומצאו שמות צבעים. בכל שורה העמודה "צבע" ממתינה לנתונים הרשמיים.

## כללים לכל התמונות

| | |
|---|---|
| פורמט | WebP (מועדף) או PNG |
| רקע | שקוף, אם אפשר |
| גודל | רוחב 1600px לתמונת סטודיו. האופנוע שלם, בלי חיתוך, בפרופורציות המקוריות |
| שמות קבצים | אותיות לועזיות קטנות, ספרות ומקפים בלבד. בלי רווחים ובלי עברית |
| צבע | תמונה אמיתית לכל צבע. אין לצבוע תמונה מחדש בעיבוד |

## 1. תמונות סטודיו – לכל דגם, רמת גימור וצבע

שם הקובץ: `<רמת-גימור>--<צבע>.webp`
- `standard`: דגם בלי רמת גימור, או הגרסה הרגילה.
- `<צבע>`: שם הצבע באנגלית, כפי שמופיע בקטלוג. לדוגמה, אם הצבע הרשמי הוא "Rebel Blue", שם הקובץ הוא `standard--rebel-blue.webp`. זו דוגמה לכתיבה בלבד, לא צבע מאומת.
