# Royal Enfield Israel – דף נחיתה

דף נחיתה סטטי (HTML + CSS + JS, ללא build) עבור Royal Enfield ישראל – ד.ל.ב מוטוספורט.
הלקוח בוחר דגם, רמת גימור וצבע, ממלא פרטים, ונפתחת הודעת WhatsApp מוכנה למספר הלידים. אין CRM ואין שמירת לידים.
העיצוב משחזר את דף הנחיתה הקיים לפי צילום המסך: רקע שמנת, רשימת דגמים מימין, האופנוע במרכז, טופס כחול עם מסגרת זהב משמאל.

## מבנה
```
index.html                       מבנה הדף
assets/data/models.js            הגדרות + רשימת הדגמים  ← הקובץ היחיד שצריך לערוך לעדכון תוכן
assets/css/styles.css            עיצוב
assets/js/app.js                 בחירת דגם/גימור/צבע ושליחה לוואטסאפ
assets/images/brand/             לוגואים
assets/images/models/<id>/       תמונות סטודיו לכל דגם (לפי צבע)
vercel.json                      הגדרות Vercel (cache, headers)
```

## עדכון תוכן (`assets/data/models.js`)
- **מספר וואטסאפ / טלפון / קישורים** – באובייקט `RE_CONFIG` בראש הקובץ.
- **מחיר** – שדה `price` של רמת הגימור (מספר בלי פסיקים).
- **רמות גימור** – מערך `trims`. דגם עם רמה אחת לא מציג בורר גימור. `name: ''` = הגרסה הרגילה.
- **צבעים** – מערך `colors` בתוך כל רמת גימור:
  ```js
  { name: 'אדום', swatch: ['#8a1c1c'], image: 'assets/images/models/meteor-350/stellar-red.webp' }
  ```
  `swatch` מקבל צבע אחד או שניים (עיגול דו־גוני). כל צבע צריך תמונה אמיתית משלו.
- **משפטים שיווקיים** – `phrases`, בדיוק שלושה.
- **סדר הדגמים** – סדר האובייקטים במערך `RE_MODELS`.
- **סרטון** – `video`. ריק = הקישור "לצפייה בסרטון" לא מוצג.

תמונות: PNG/WebP עם רקע שקוף, האופנוע שלם ללא חיתוך, רוחב מומלץ 1600px. בלי תמונה מוצג שם הדגם כמציין מקום.

קישור ישיר לדגם (למודעות): `/#meteor-350` (לפי `id`).

## מה עוד חסר (לא הומצא – ממתין לנתונים רשמיים)
- צבעים ותמונות סטודיו לכל דגם / רמת גימור.
- קישורים לתנאי שימוש ומדיניות פרטיות ולהצהרת נגישות (`termsUrl`, `accessibilityUrl`).
- לוגואים באיכות מקור – הקבצים ב-`assets/images/brand/` נחתכו זמנית מצילום המסך.
- דרגת זיהום אוויר – מוגדרת כרגע 2 לכל הדגמים (כמו בדף הקיים). אפשר להגדיר `pollutionGrade` לכל דגם בנפרד.

## הרצה מקומית
```
npx serve .
```

## פרסום ב-Vercel
לייבא את ה-Repository ב-Vercel, Framework Preset: **Other**, ללא Build Command ו-Output Directory.
כל הנתיבים בקוד יחסיים לשורש האתר, כך שחיבור הדומיין `royal-enfield-israel.co.il` בהמשך לא דורש שינוי קוד – רק הוספת הדומיין בהגדרות הפרויקט ב-Vercel ועדכון DNS (בשלב מאוחר יותר, אחרי אישור האתר).

## מדידה (Google Tag Manager)
להפעלה: `gtmId` ב-`RE_CONFIG`. אירועים שנשלחים ל-dataLayer:
- `whatsapp_lead` – שליחת טופס (`model`, `trim`, `color`, `marketing_consent`)
- `whatsapp_click` – לחיצה על כפתור הוואטסאפ הצף (`cta_location: 'float'`)
